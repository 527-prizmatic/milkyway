# Milky Way 👾
A clone of the 1978 arcade game *Space Invaders*, developed as a team of two in two days, as part of the first formation year in French video game school Game Academy.

All graphical assets and sound effects are free of charge, but background musics were taken from the 1999 game *Space Invaders X*.
Due to a lack of technical knowledge, some areas of the gameplay are a bit unstable, as alternate methods had to be found to bypass our shortcomings.

## Tools & Techs :wrench:
- **Languages** - C, GLSL
- **IDEs** - Microsoft Visual Studio 2022
- **Additional Libraries** - CSFML 2.5.1
